# منصة المُبدع Mobile V7 — Android Diagnostics & Cloud Sync

## الجديد المنفذ فعليًا
- شاشة تشخيص داخل التطبيق لاختبار Android والكاميرا وBarcodeDetector والصوت العربي والتخزين والإنترنت والمزامنة.
- قفل تلقائي حقيقي بعد مدة عدم الاستخدام.
- عميل مزامنة سحابية: اختبار اتصال، رفع البيانات، وتنزيلها.
- خادم Cloudflare Worker جاهز داخل `cloud-worker` مع حماية Token وفصل البيانات حسب مساحة العمل.
- إعداد GitHub Actions لإنتاج APK Debug تلقائيًا مع صلاحيات CAMERA وINTERNET.
- دليل اختبار حقيقي على الموبايل والتابلت.
- استمرار كل وظائف V6: الطلاب، الحصص، وضع الحصة، الحضور، الأصوات، الرسائل، الدرجات، الألعاب، الكروت، التقارير، النسخ الاحتياطي، ومعاينة الطالب وولي الأمر.

## مهم
- تم تجهيز كود الاختبارات والبناء، لكن نتيجة الكاميرا والصوت على جهاز Android لا يمكن تأكيدها إلا بعد تثبيت APK على الجهاز ومنح الصلاحيات.
- المزامنة تعمل بعد نشر Cloudflare Worker وإدخال الرابط والرمز السري في الإعدادات.
