# منصة المُبدع — الإصدار 9.3.0

تطبيق تعليمي يعمل على الويب وAndroid باستخدام React وVite وCapacitor، ويضم إدارة الطلاب والحضور والدرجات والمدفوعات والمحتوى ووضع الحصة والألعاب والتقارير والنسخ الاحتياطي والمزامنة السحابية.

## أهم الإصلاحات في هذه النسخة

- إلغاء أرقام الدخول الافتراضية وإجبار الإدارة والمعلم على إنشاء أرقامهم عند أول تشغيل.
- حماية أرقام الدخول وعبارة الاسترجاع باستخدام PBKDF2-SHA-256 مع أملاح عشوائية وقفل تصاعدي للمحاولات المتكررة.
- تشفير قاعدة البيانات المحلية والملفات الحساسة باستخدام AES-GCM، مع حفظ مفتاح Android داخل Keystore ومفتاح Web Crypto غير قابل للاستخراج داخل IndexedDB للويب.
- فصل الصور وPDF والصوت والفيديو عن JSON وحفظها مشفرة في IndexedDB، مع حد حجم واضح لكل ملف.
- نسخ احتياطية مشفرة بكلمة مرور وتحقق مصادق يمنع قبول ملف تم العبث به.
- مزامنة Cloudflare مع Token مستقل لكل مساحة عمل، وتشفير خادمي، ومنع الكتابة فوق نسخة أحدث.
- مزامنة الملفات المشفرة عبر R2 مع SHA-256 قبل الرفع وبعد التنزيل.
- روابط مشاركة حقيقية بين الأجهزة للبيانات الكبيرة، مع حذف الحقول الحساسة وانتهاء صلاحية الروابط البعيدة.
- تحديث APK لا يقبل إلا HTTPS ويتحقق من الحجم وSHA-256 واسم الحزمة وتوقيع التطبيق.
- توحيد الإصدار بين الويب وAndroid والنسخ الاحتياطي والمزامنة.
- إصلاح مسارات PWA وService Worker للنشر داخل مسار فرعي.
- إضافة اختبارات وفحوص جودة وGitHub Actions لبناء Debug وإصدار APK/AAB موقّع.
- تطوير لوحة التحكم لتطابق التكوين المرجعي وربط كل بطاقة وزر بالمنصة.
- إضافة سبورة مستقلة كاملة وكتابة فوق الصور وصفحات PDF عبر Renderer أصلي على Android.
- تحسين كروت الطلاب والطباعة المزدوجة ومحاذاة الوجه الخلفي مع الأمامي.
- تطوير تحدي الخرائط إلى واجهة لعب احترافية بخمسة أوضاع وخرائط GeoJSON حقيقية.
- استكمال وضع الحصة بحفظ طبقات الكتابة والتحديد والتحريك والتسجيل وقائمة الطلاب التفاعلية.
- تحويل المكتبة إلى مصدر موحد: كتاب رئيسي وملف امتحانات رئيسي لكل صف، ودروس بصفحات ووسائط وواجبات محفوظة.
- تحميل كتاب الدرس وصفحاته وصوره وفيديوهاته وصوته وملفاته تلقائيًا داخل وضع الحصة.
- إضافة استوديو خرائط شرح حسب الصف، مع جبال وهضاب وسهول ومنخفضات وأنهار وثروات وظواهر جغرافية قابلة للرسم والحفظ.
- ربط المكتبة ببنك الأسئلة والامتحانات والواجبات والتقارير والمزامنة السحابية.

## التشغيل المحلي

المتطلبات:

- Node.js 22 أو أحدث متوافق.
- npm.
- Android Studio وJDK 21 لبناء Android.

```bash
npm ci
npm run verify
npm run dev
```

## تجهيز Android

```bash
npm run cap:sync
npm run cap:open:android
```

لبناء Debug من سطر الأوامر:

```bash
npm run android:debug
```

لبناء Release يجب توفير متغيرات توقيع Android الموضحة في `ANDROID_RELEASE_AR.md`.

## أول تشغيل

لا توجد أرقام دخول افتراضية. ستطلب شاشة القفل إنشاء:

1. رقم إدارة من 6 إلى 10 أرقام.
2. رقم معلم من 6 إلى 10 أرقام.
3. عبارة استرجاع طويلة تحفظ في مكان آمن.

دخول الطالب وولي الأمر يحتاج إلى أرقام مستقلة تُنشأ من شاشة إدارة الطلاب؛ كود الطالب وحده لا يكفي للدخول.

## ملاحظات أمان مهمة

- لا تضع Tokens أو كلمات مرور أو ملف Keystore داخل المستودع.
- استخدم Token عشوائيًا مختلفًا لكل مساحة عمل.
- لا تغيّر `MOBDEA_ENCRYPTION_KEY` بعد بدء استخدام المزامنة؛ تغييره يجعل البيانات القديمة غير قابلة للفك.
- احتفظ بنسخة احتياطية مشفرة قبل أي ترقية إنتاجية.
- اختبر الكاميرا والصوت والتثبيت على أجهزة Android الفعلية قبل النشر العام.
