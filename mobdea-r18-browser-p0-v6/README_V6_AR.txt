- PDF: رسم الصفحة عبر pdf.js ثم عرضها كصورة فعلية داخل مساحة الحصة، مع إظهار الخطأ بدل شاشة سوداء صامتة.
- Images: مساحة عرض كاملة + أوضاع احتواء / ملء العرض / ملء الشاشة.
- Lesson Maps: الخريطة لا تتقلص عند فتح الأدوات، وDrawer الرموز قابل للتمرير الرأسي باللمس.
- Required maps: مصر، الوطن العربي، إفريقيا، آسيا، أوروبا، العالم ظاهرة بوضوح في Drawer الخرائط.
- Map Challenge: نفس الخرائط الستة ظاهرة في شريط الاختيار.
- Map symbols: SVG relief أقوى للجبال والهضاب والسهول والصحارى، مع عرض الشكل فقط على الخريطة.
- Historical board: إطار بردي/حجر/ذهب وعناصر أثرية ذات عمق بصري مع إبقاء مركز الكتابة واضحًا.
