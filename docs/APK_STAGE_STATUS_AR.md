# حالة مرحلة APK — منصة المُبدع V8

## تم تنفيذه داخل المشروع
- إنشاء مشروع Android فعلي داخل مجلد `android`.
- دمج ملفات الويب الأخيرة داخل Android عبر Capacitor.
- إضافة صلاحيات الكاميرا والإنترنت وحالة الشبكة والإشعارات.
- السماح بالتثبيت على الأجهزة التي لا تحتوي على كاميرا مع بقاء الإدخال اليدوي متاحًا.
- تثبيت اسم الحزمة: `com.mobdea.education`.
- إصدار Android: `8.0.0` ورقم بناء `8`.
- إضافة أيقونة التطبيق المعتمدة لكل كثافات شاشات Android.
- إعداد GitHub Actions لإنتاج APK قابل للتثبيت من الموبايل دون كمبيوتر.
- التحقق محليًا من نجاح Web Build وCapacitor Sync.

## ما لا يمكن اختباره داخل بيئة المحادثة
- تشغيل APK على موبايل أو تابلت حقيقي.
- موافقة المستخدم على إذن الكاميرا.
- جودة نطق أسماء الطلاب حسب صوت TTS العربي المثبت على الجهاز.
- فتح واتساب والطباعة من الجهاز الفعلي.

## طريقة استخراج APK من الهاتف
1. ارفع محتويات المشروع إلى مستودع GitHub.
2. افتح تبويب Actions.
3. افتح `Build Mobdea V8 Android APK`.
4. اضغط `Run workflow`.
5. بعد ظهور العلامة الخضراء، حمّل Artifact باسم `mobdea-mobile-v8-apk`.
6. فك الضغط وثبت `mobdea-mobile-v8-debug.apk`.
