# المرحلة الأولى — الهوية والرئيسية والقائمة

## تم تنفيذه في الكود
- إعادة تصميم القائمة الجانبية بالكامل بهيكل واضح ووصف لكل قسم.
- جعل القائمة قابلة للتمرير مستقلًا حتى لا تختفي الحسابات والإعدادات.
- إضافة Safe Area أعلى وأسفل ويمين ويسار لدعم أزرار نظام أندرويد والنوتش.
- إضافة رأس موبايل ثابت مع زر القائمة وتنبيهات الرسائل.
- إعادة تصميم الصفحة الرئيسية بهوية أسود وذهبي.
- بطاقة بارزة للحصة الحالية مع عدد الطلاب والحضور والغياب.
- إجراءات سريعة: وضع الحصة، الحضور، رصد الدرجات، الدرجات، الألعاب، إضافة طالب.
- عرض طلاب المجموعة الحالية وحالة الحضور.
- لوحة متفوقي المجموعة.
- تنبيهات الرسائل والمستحقات والتقارير.
- تحديث رقم نسخة المصدر إلى 8.2.0.

## يحتاج أصلًا من المستخدم
- الصورة الشخصية الأصلية للأستاذ مصطفى لا توجد داخل ملف المشروع المرفوع؛ لذلك تم تثبيت هوية مؤقتة بحرف «م» بدون اختلاق صورة أو تغيير ملامح.
- عند توفير الصورة الأصلية عالية الجودة، تُستخدم للأيقونة وSplash والواجهة في تحديث الهوية التالي.

## ملاحظة تحقق
تمت مراجعة بنية الكود والتعديلات، لكن تعذر إكمال npm install محليًا داخل بيئة التنفيذ بسبب تعليق تنزيل الحزم. يظل GitHub Actions هو مسار التحقق والبناء الذي نجح سابقًا للمشروع.
