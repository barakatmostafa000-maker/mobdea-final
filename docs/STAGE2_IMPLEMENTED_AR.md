# المرحلة الثانية — وضع الحصة والشرح وجهات الاتصال

تم تنفيذ واختبار البناء بنجاح في الإصدار 8.3.0.

## المنفذ فعليًا
- وضع حصة احترافي للمجموعة الحالية فقط.
- مؤقت للحصة مع إيقاف واستكمال وإعادة ضبط.
- عدادات الحضور والغياب والطلاب لحظيًا.
- حضور، غياب، تأخر، وغياب بعذر.
- اختيار طالب عشوائي.
- نقاط فورية لكل طالب.
- اختصارات صوتية متنوعة.
- جمل بصوت زهقان منها: «اتقي الله يا [الاسم]» و«يا رب استرها علينا من [الاسم]».
- عدم تكرار الجملة نفسها مباشرة.
- حفظ ملخص الحصة عند الإنهاء: الوقت، الحضور، النقاط والملاحظات.
- شاشة شرح داخل وضع الحصة.
- سبورة قابلة للرسم باللمس أو الماوس.
- قلم، هايلايتر، ممحاة، مسح وحفظ السبورة كصورة.
- أزرار مصادر الشرح: PDF، صورة، عرض وتصوير السبورة كواجهة جاهزة للربط.
- ملاحظات المعلم وملخص الواجب والمتابعة.
- وضع ملء الشاشة للحصة.
- زر جهات الاتصال بجوار رقم ولي الأمر ورقم الطالب.
- تنسيق الأرقام المصرية ومنع التنسيق الخاطئ.
- تنبيه عند تكرار الرقم مع طالب آخر.
- fallback واضح إذا لم يدعم الجهاز Contact Picker API.
- تحسين رسالة الترحيب عند فتح التطبيق.
