# إعداد مزامنة منصة المُبدع

النسخة V7 تحتوي على عميل مزامنة فعلي، ومعه خادم Cloudflare Worker بسيط داخل مجلد `cloud-worker`.

## ما يحتاجه الخادم
- حساب Cloudflare.
- إنشاء Workers KV باسم مناسب.
- ربط KV بالمتغير `MOBDEA_DATA`.
- إضافة Secret باسم `MOBDEA_TOKEN`.

بعد نشر Worker، انسخ رابطه إلى: الإعدادات ← المزامنة السحابية.

مثال للرابط:

```text
https://mobdea-sync.<your-subdomain>.workers.dev
```

أدخل:
- مساحة العمل: اسم خاص، مثل `mostafa-center-main`
- الرمز السري: نفس قيمة `MOBDEA_TOKEN`

## طريقة العمل
- «رفع الآن» يحفظ نسخة المنصة كاملة على السحابة.
- «تنزيل الآن» يستبدل البيانات المحلية بآخر نسخة سحابية بعد تأكيد المستخدم.
- الرمز السري لا يُرفع داخل بيانات النسخة السحابية.

## مهم
الخادم لا يعمل قبل نشر Worker وربط KV وإضافة الرمز السري. بدون ذلك تظل المنصة تعمل Offline بشكل كامل.
